# 一、论文所属课题来源、名称、编号

【保留并校正】课题来源：国家自然科学基金。课题名称：贵州省地氟病骨骼病变图像的智能检测与识别。课题编号：62266011。【待核实】本研究聚焦氟斑牙口内图像，与基金项目名称中的“骨骼病变图像”不完全一致，须由导师确认本论文与该项目的任务关联及可使用的数据范围。

# 二、立项依据与研究内容

## 1. 论文立项依据

### 1.1 研究背景与问题界定

【重写】氟斑牙是牙齿发育期间过量摄入氟所致的釉质改变。口内照片能够保留釉面不透明、着色和缺损等可见表现，已有研究将照片用于氟斑牙分级，也报告了照片评估与临床检查之间的一致性[1-3]。但照片只呈现拍摄时可见的牙面，不能单独证明暴露史、排除所有相似釉质病变，更不能代替口腔医生的临床诊断。本研究因此将输出限定为**基于口内照片的分级辅助意见及可复核报告草稿**。

【重写】已有氟斑牙图像研究主要回答“属于哪个级别”。Gu 等提出分割与分类的两阶段方法[4]；Xu 等发布 DFID 数据集并以 MLTrMR 做四级分级，论文报告数据集包含 131 张图像，其中正常、轻度、中度、重度分别为 26、49、36、20 张[5]。这些工作为图像分级提供了可比较基线，但公开论文没有提供可直接用于本课题的逐征象区域标注和医生报告文本。因此，从图像级类别跨到带依据的报告，需要另外建立标注与评价数据；不能把分类准确率等同于报告可信度。

【重写】拟解决的核心矛盾是：一个分级结论可以在图像级评测中被判为“正确”，报告中的“哪颗牙、何种征象、是否存在缺损”却仍可能与照片不符。报告一旦直接描述图像未显示的内容，医生就无法依照原图复核。因此，本研究将**可观察征象**作为分类与报告之间的中间表征：先记录区域和征象，再形成分级辅助意见，最后把已确认字段写成短报告。对于模糊、遮挡、严重反光或征象相互矛盾的图像，系统保留“不可判断/需复核”，不强行出具确定级别。

【新增】本研究的主要科学问题不是设计一个同时包含 CNN、Transformer、EDL、RAG、LoRA 的系统，而是检验：**显式的局部征象表征和证据约束，相比仅将分级标签输入报告生成器，能否减少无图像依据的报告陈述，同时保持分级性能和合理的人工复核负担？**这一问题可以通过同一测试集上的对照实验回答。

### 1.2 国内外研究现状及不足

【重写】**氟斑牙照片分级。**照片评估的可行性已有研究基础，但不同评分体系并不自动等价。Pretty 等在 164 名儿童的研究中比较临床检查与照片评分，报告观察者间一致性随方法和评分条件变化[2]。Wongkhuenkaew 等利用颜色和不透明区比例进行四级照片分类[3]；Gu 等、Xu 等则分别研究分割辅助分类和视觉特征学习[4-5]。上述研究的类别定义、样本量与影像来源不同，不能将各论文分数直接横向排名。对本课题而言，真正缺少的是与分级结论配套的局部征象依据和结构化报告标注。

【重写】**影像报告生成与定位。**医学影像报告生成已有从图像到自由文本的编码解码研究，如 Jing 等[6]和 Chen 等[7]。MAIRA-2 进一步研究胸片报告陈述与图像位置的对应关系[8]。这些方法说明“报告文字需要被影像证据支持”是可研究的问题，但胸片与口内照片的解剖结构、报告长度和标注体系不同，不能直接把其效果推广到氟斑牙。针对本课题，更合适的目标是短字段与短叙述，而非完整临床病历或自动诊断书。

【重写】**外部知识与拒判。**检索增强生成（RAG）可将外部文本作为生成时的上下文[9]；Almanac 在临床知识问答中评估了经检索增强的回答[10]。二者均不能证明检索文本能够替代口内照片的观察结果。另一方面，选择性分类研究提出以覆盖率和风险共同衡量“只对部分样本输出结论”的机制[11]。本研究据此把知识检索作为可选的**规范性说明模块**，仅用于解释评分规则或术语；图像征象仍必须由照片及医生标注支持。拒判阈值应在验证集确定，再在独立测试集报告风险—覆盖率曲线。

【新增】综上，现有文献能够分别支持照片分级、影像报告生成、图像定位和选择性预测，但尚不能证明它们串联后会改善氟斑牙报告质量。本研究的增量在于建立同一批病例上的“图像区域—征象字段—分级结论—报告陈述”对应关系，并以无依据陈述和人工复核量检验其价值。

### 1.3 研究价值与适用边界

【重写】预期学术价值是提出并检验一种面向小样本口内照片的可追溯报告流程，明确图像级分级与字段级事实性之间的差别。预期应用价值是为医生提供可核对的筛查记录草稿，而不是宣称自动降低误诊率或直接用于临床决策。系统只能描述输入图像可见的牙面；对拍摄质量不合格、牙位不明、疑似非氟斑牙病变或证据不足的病例输出复核提示。是否用于真实工作流，须另经伦理、数据合规和前瞻性评价。

## 2. 研究内容、目标与关键问题

### 2.1 研究内容

【新增】研究对象限定为**口内可见牙面照片**。报告单位先固定为单张图像，可见牙区作为证据单位；若数据中有可靠牙位信息，再扩展到单牙报告。分级标签沿用已核验数据的原始四级定义，不自行以“牙面 1/2”等阈值重造标准。临床医生在预标注阶段确认等级定义、征象词表与可判读条件。所有模型训练和评价均以该版本的标注手册为准。

【重写】**研究内容一：建立可复核的征象标注集。**盘点团队现有口内图像的患者数、图像数、来源、原始分级、牙位信息、拍摄质量和可使用授权；去重后按患者划分训练、验证和测试集。先选择 30—50 张覆盖四级和质量问题的图像，由两名口腔医生独立标注牙区、可见征象、分级与“不可判断”，对分歧进行仲裁；修订并冻结标注手册后再扩大标注。若无法获得两名医生和足够病例，则缩小任务为图像级分级加图像级字段报告，不声称区域定位。输出物为标注手册、数据字典、版本化病例表及一致性统计。

【重写】**研究内容二：从局部征象形成分级依据。**以已验证的分级模型[4-5]或常规 CNN/ViT 作为基线，比较“直接图像分类”与“牙区定位/征象预测后分类”两种路径。局部区域可以采用医生框/掩码监督的检测或分割模型；没有区域真值的样本只参与图像级任务，不用于定位指标。每条证据记录图像编号、牙区、征象类型、区域坐标、模型分数及人工标注状态。分级模型的有序损失和不确定性方法为候选改进，只有在验证集较基线带来稳定收益时纳入最终方案；EDL 不被预设为必然优于普通置信度校准[12-13]。

【重写】**研究内容三：生成受证据约束的报告草稿。**先定义最小报告字段：图像质量、可见牙区、阳性征象、明确可见的阴性征象、分级辅助意见、证据定位和复核状态。以“结构化字段→固定模板短叙述”为主方法，保证每句可回溯；对照方法使用相同报告字段，但直接从整图预测征象与级别，不使用区域证据。仅当医生报告样本量足够且模板基线显示明显不足时，才试验小模型/LoRA 适配[14]。RAG 仅为报告附加经医生确认的评分说明；不参与补写图像征象。系统对未被证据支持的字段拒绝输出，对低质量或证据冲突病例标注需人工复核。

【配图位置：图 2。研究主线图：口内照片与质量筛查 → 医生征象标注/局部预测 → 分级辅助意见 → 结构化字段 → 模板短报告 → 证据检查与医生复核。用实线表示必做模块，虚线表示数据允许后才做的知识检索和生成模型。】

### 2.2 研究目标与可交付结果

【重写】目标一：形成可复现的四级图像数据划分、征象字段定义和小规模双医生标注集，报告标注一致性与不可判断比例。目标二：在患者级独立测试集上，检验局部征象路径相对直接分类基线的分级性能与区域定位质量。目标三：在同一测试病例上，检验受证据约束的短报告相对仅由分级标签生成的报告，是否降低无依据陈述率与医生修改量，并报告其对覆盖率的影响。最终交付数据字典、实验代码、匿名化评测表、报告原型和论文；病例原图及医生记录的公开范围以授权为准。

### 2.3 拟解决的关键问题

【重写】（1）四级标签与可见征象之间怎样形成稳定、可复核的标注关系？难点是相邻等级、拍摄条件和非氟斑牙相似征象造成的分歧。解决途径是冻结标注规则、记录分歧，并对“不可判断”单独建模。

【重写】（2）局部征象能否实质性支持分级，而非仅产生看似合理的热图？解决途径是区域标注、定位指标和遮挡/替换对照实验；仅有可视化图不能证明证据有效。

【重写】（3）报告怎样限制在图像和审核知识的支持范围内？解决途径是结构化字段、句子级证据映射、自动规则检查及医生盲评；以无依据陈述和漏报而非语言流畅度作为主要评价。

## 3. 研究方案及可行性分析

### 3.1 数据与标注方案

【新增】首先建立数据台账，至少记录患者 ID、图像 ID、拍摄时间/机构、原始标签、牙位可判定性、授权与质量标记。对同一患者的多张照片进行患者级划分，避免泄漏。保留测试集原始分布，除预先约定的质量排除外不因模型错误而删样本。公开 DFID 用于分类复现与对照；自有数据承担征象、定位和报告评价。若 DFID 的患者级元信息不可获得，仅使用其作者公布划分或在论文中说明限制，不声称患者级独立性。

【新增】医生标注表包含 image_id、region_id、可见牙位/牙区、征象（不透明、着色、表面缺损等）、区域框/掩码、等级、质量状态和标注者。否定字段仅在对应牙面清晰可见且医生明确确认时填写；未见与不可见严格区分。先做 30—50 例试标是为了校正规则，不能以这批样本直接声称训练集足够。正式标注规模依据数据盘点和一致性结果确定。【待核实】现有自有数据量、可用的医生人数、伦理批件/知情同意、外部机构数据来源。

【配图位置：图 3。标注样例图：一张去标识化照片与其结构化标注表并列，标出区域坐标、征象和不可判断字段；取得授权后制作。】

### 3.2 模型与报告流程

【重写】第一步复现图像级四级分级基线，报告类别样本数、macro-F1、各类召回率与二次加权 Kappa（QWK）。第二步训练局部牙区/征象模型，比较有无局部监督对分级的影响；按标注类型分别评价区域 IoU 或框 mAP、征象字段 F1。第三步将模型输出转为结构化事实表，其中每个阳性陈述必须携带区域 ID；分级意见关联支持它的征象 ID。第四步由模板生成短报告，例： “本图可见〔牙区〕〔征象〕，图像级辅助分级为〔级别〕；〔未可判定项目〕需医生复核。”模板只填入已核验字段，不加入病因、治疗、预后和未观察牙面。第五步核查字段、区域和短叙述的一致性，冲突或质量不足则拒绝自动分级并生成复核提示。

【新增】若进行知识检索，知识库只收录可核实的评分标准、诊断图谱或临床共识，逐条保存出处、页码、适用条件、版本与医生审核状态。检索返回的内容放在“参考说明”字段，与“图像观察”分栏展示；未审核或无法定位原文的条目不进入报告。可用检索质量、引用支持率评价该附加模块，但它不作为主线完成的前提。

【配图位置：图 4。报告草稿示例：左侧原图及征象位置，右侧结构化字段和短报告；用编号连接每句文字与图像区域，知识说明单独成栏。】

### 3.3 对照实验、评价指标与判定方式

【新增】主要对照设为 A：整图直接预测征象字段和分级标签，再用固定模板生成报告；B：图像经局部征象表形成同样的字段和分级标签，再用相同模板生成报告。两组使用相同病例划分、标注量、报告字段和模板，主要区别是 B 有局部区域监督与证据定位；另可报告“只给分级标签”的极简模板作为任务下界，但不纳入主要事实性比较。若比较自由文本模型 C，必须使用相同可获得的信息，并单独报告训练数据量与成本。消融实验依次去掉区域监督、征象字段和拒判规则，以判断性能改变来自哪个环节。知识检索与 LoRA 为可选附加实验，不混入主要结论。

【新增】主要终点为医生判定的**每份报告无图像依据陈述比例**，同时报告有依据陈述召回率，防止系统靠少写内容取得表面优势。次要终点为分级 macro-F1/QWK、征象字段 F1、区域定位指标、结构有效率、医生修改字数/时间，以及拒判率下的错误率。由两名医生在隐藏方法来源后独立审阅报告；审阅分歧仲裁，报告一致性。用患者级 bootstrap 给出主要指标差值的 95% 置信区间。由于病例量可能较小，结果重在估计效应和误差范围，不承诺统计显著。拒判阈值仅用验证集确定，在测试集画风险—覆盖率曲线。

【新增】外部验证是**条件性目标**：只有取得独立机构、同模态、可合法使用且标注规则一致的数据时才实施。若拿不到，诚实报告同机构时间/设备分层测试及局限，不把 DFID 与自有数据的简单混用称为外部验证。对医生工作流的收益也只在实际盲评和修改时间实验完成后讨论。

### 3.4 可行性与风险应对

【重写】现有基础是导师团队从事地氟病影像研究，且已有公开 DFID 与相关分级论文可作技术基线[4-5]；实验室据 v4 描述具备 GPU 环境，但计算资源型号、数据权限和医生标注安排尚无可核实记录，不能以“项目充分可行”一笔带过。最大的风险是**征象与报告标注不足**，其次是四级类别不平衡、跨拍摄设备差异和高等级样本稀少。对应措施是先完成数据台账与试标，再决定定位与生成任务规模；采用患者级划分、类别分层报告和置信区间；以模板报告作为最低可交付方案。项目与基金课题的对应关系、伦理合规、图像授权和报告真实使用场景均须在开题前由导师确认。

## 4. 预期创新点

【重写】（1）**图像征象到报告陈述的显式映射。**在氟斑牙照片分级与短报告之间引入可标注、可定位的征象表，并用对照实验验证该表能否减少无依据陈述。创新性以实验结果为准，不把“增加证据 ID”本身等同于方法创新。

【重写】（2）**面向不可判断样本的报告边界。**将图像质量、证据冲突与拒判状态写入报告协议，使系统能在不足以判断时停止给出确定级别；评价同时考虑错误率和人工复核覆盖率。
