## 1.1 研究意义

地方性氟中毒（地氟病）是由于人体通过饮水、食物或空气等途径长期摄入过量氟元素而引起的系统性慢性疾病，临床症状主要包括氟斑牙和氟骨症。氟斑牙是氟暴露早期最敏感的体征，主要表现为牙釉质表面出现白垩色斑块、着色以及不同程度的牙体缺损。氟斑牙不仅影响美观，还可能增加龋齿、釉质磨损等口腔问题的风险，对儿童和青少年的身心健康产生长期影响。

中国是全球地氟病流行范围较广、受危害人口较多的国家之一，贵州省曾是世界上人口最多、病区最集中、病情最严重的地氟病重症区之一。经过多年综合防治，病区儿童氟斑牙患病程度已明显改善。遵义市播州区新民镇朝阳村的调查显示，8～12 岁儿童氟斑牙检出率由 2009 年的 33.7% 降至 2023 年的 16.4%；但同期居民对地氟病的知晓率由 100% 降至 23.3%，正确使用炉灶率虽由 0% 提高到 61.6%，健康行为习惯仍未完全巩固[1]。这说明，在防治工作取得成效的同时，基层筛查、健康教育和长期随访仍需要持续投入。

目前，氟斑牙的诊断主要依赖口腔医生对牙齿图像的肉眼观察，并依据诊断标准进行分级。人工判读存在明显不足：一是判读过程耗时，大规模筛查时需要大量重复劳动；二是分级结果受医生经验和主观判断影响，不同观察者之间的一致性有限；三是地氟病多发于农村和偏远地区，口腔专业医疗资源相对匮乏，部分基层医生难以获得及时、规范的诊断支持；四是筛查记录和报告整理缺少统一结构，后续复核、质控和流行病学统计的成本较高。

近年来，深度学习在氟斑牙图像分级方面取得了进展。Gu 等[2]建立了氟斑牙图像数据集，提出“大核卷积 U-Net 分割 + 像素关联迭代 + CNN/Transformer 双分支分类”的两阶段方法；Xu 等[3]提出随机掩码潜在 Transformer，在公开数据集 DFID 上取得 80.19% 准确率、75.79% F1 和 81.28% QWK；Li 等[4]提出轻量化 LD2Net，在保持 80.00% 准确率和 79.88% macro-F1 的同时显著降低参数量与计算量。这些工作表明，氟斑牙分级在准确率和效率上已具备较好的研究基础。然而，现有研究大多停留在“输出类别、分割掩码或热图”的层面：模型给出分级结果，却难以说明依据了哪些牙齿区域和征象；报告中的分级依据、鉴别说明和健康建议缺少可追溯的知识来源；医生在复核时仍需重新阅读图像、手工整理文字。换言之，分级模型与临床报告之间仍存在明显断层。

针对上述问题，本研究拟面向氟斑牙筛查，构建“视觉证据对齐 + 知识增强”的辅助报告生成方法：以牙齿区域定位和四级分级为基础，输出可回溯到图像区域的征象证据；以医学知识库检索补充分级依据和鉴别说明；以受约束的生成模型组织结构化字段与短叙述报告，并将低置信度样本转交医生复核。本研究的意义主要体现在三个方面：（1）面向基层筛查，降低人工判读和报告整理成本，提高筛查效率；（2）通过视觉证据与知识证据的分开溯源，提高报告的可解释性和可审核性，为医生复核提供依据；（3）为地氟病防治档案、健康教育和流行病学统计提供结构化数据基础。需要强调的是，本系统输出的是医学辅助分析结果，不替代临床诊断，最终报告须由执业医师审核确认。

## 1.2 国内外研究现状及发展动态分析

近年来，随着人工智能和医学影像分析的发展，氟斑牙的自动分级与医学报告生成受到越来越多关注。本节从氟斑牙影像分级、医学报告生成与视觉语言模型、知识增强与检索增强生成、可信评价与不确定性四个方面梳理研究现状，并分析现有工作的不足。

### （1）氟斑牙影像分级研究

氟斑牙分级的核心难点在于病灶区域小、边界不清、表现受染色和光照影响，且不同级别之间存在相邻类别混淆。Gu 等[2]针对这些问题建立了氟斑牙图像数据集，第一阶段采用大核卷积 U-Net 分割牙齿区域，并通过像素关联迭代算法优化分割结果；第二阶段设计 CNN 与 Transformer 双分支融合分类器，使模型在病灶占比较小时仍能关注关键区域。Xu 等[3]提出随机掩码潜在 Transformer（MLTrMR），通过潜在嵌入和掩码 token 预测增强模型对氟斑牙特征的上下文建模能力，在 DFID 上取得 80.19% 准确率、75.79% F1 和 81.28% QWK。Li 等[4]提出 LD2Net，采用强化深度可分离卷积和双轴集成注意力，在保持 80.00% 准确率和 79.88% macro-F1 的同时，将参数量和计算量降低 80% 以上，为资源受限场景提供了轻量化方案。除氟斑牙外，Xu 等[5]针对氟骨症 X 线影像提出 Mwinc-Mamba，将 CNN 与状态空间模型结合，在 SFXRay 数据集上取得二分类 83.33%、多分类 66.67% 的准确率；该工作说明 CNN 与全局建模结合对氟中毒相关影像分级具有参考价值，但其任务是氟骨症 X 线，不能直接作为氟斑牙照片任务的外部验证。尹子源等[6]提出 QOD-UNeXt，通过四象限斜向特征位移和局部特征融合实现轻量牙齿图像分割，为牙齿区域定位提供了可借鉴的方案。

总体来看，氟斑牙分级已从传统机器学习发展到深度学习方法，准确率和轻量化程度不断提升；但现有研究多以图像级分类为终点，输出类别概率、分割掩码或热图，缺少对“哪个牙位、哪个牙面、何种征象支持该级别”的结构化表达。同时，公开数据规模仍然有限，DFID 仅有约 200 个样本[4]，数据划分、跨中心验证和报告标签建设仍是后续研究需要解决的问题。

### （2）医学报告生成与视觉语言模型

医学图像报告生成早期主要采用 CNN-RNN 编码器—解码器、检索—生成混合模型和记忆驱动 Transformer 等结构[7-9]。近年来，通用视觉语言模型和医学基础模型的发展，使报告生成从模板填充走向端到端生成[10-11]。在牙科领域，Zhu 等[12]提出实例引导的视觉语言模型，用于全景片的临床级解读；MICCAI 2026 ODIN 挑战赛设置了基于 CBCT 和口内扫描的牙科报告生成任务，已有工作采用 Qwen2.5-VL 等开源视觉语言模型进行 LoRA 微调，并以结构化牙位图或字段代替自由文本[13]。这些工作表明，牙科报告生成正从“自由文本”转向“结构化输出”，但研究对象多为全景片、CBCT 或口内扫描，针对氟斑牙口内照片、强调分区视觉证据与知识溯源的研究仍较少。通用视觉语言模型虽然语言表达流畅，但容易出现视觉事实错误、术语不规范和“看似合理却无图像依据”的描述，直接用于筛查报告存在风险。

### （3）知识增强与检索增强生成

检索增强生成（RAG）通过外部知识检索为语言模型提供证据，已在医学问答和报告生成中得到应用[14-16]。在放射学报告生成中，事实感知的多模态检索能够提升报告的事实一致性[17]；多步检索与推理也被用于改善放射学问答的准确性和幻觉控制[18]。在医学知识库建设中，知识条目需要保留来源、版本和审核记录，否则检索结果难以复核。需要指出的是，RAG 可以补充医学知识、改善术语和鉴别说明，但不能恢复图像中缺失的证据；视觉不确定性与知识不足是两个正交问题，应分别验证。现有牙科 RAG 研究多面向问答或诊断建议，面向氟斑牙分级报告、且将“图像可证”与“知识可证”分开评价的工作仍较少。

### （4）可信评价与不确定性

在临床应用中，模型不仅需要给出分级，还需要说明“有多确定”。证据深度学习（EDL）通过 Dirichlet 分布建模分类证据，可同时输出类别概率、证据强度和不确定性[19]；温度缩放、ECE、Brier 分数等校准方法可用于评价置信度是否可靠[20]；选择性预测则通过风险—覆盖率曲线决定哪些样本应转人工[21]。现有氟斑牙分级研究多报告准确率、F1 和 Kappa，较少同时报告校准、选择性预测和报告级事实性；在跨中心、跨设备场景下，置信度是否仍然可用仍缺少验证。

### （5）小结

综上所述，现有研究存在三个主要缺口：一是分级模型与报告生成相互分离，分级结果难以转化为可审核的结构化报告；二是视觉证据与语言描述之间缺少稳定对齐，报告中的征象、否定和不可判断项难以回溯到图像区域；三是知识证据与图像证据未分开溯源，报告的事实性、引用覆盖率和引用支持率缺少可复现的评价。针对这些缺口，本研究拟构建“视觉证据对齐 + 知识增强”的氟斑牙分级辅助报告生成方法，将分级、证据对齐、知识检索和受约束报告生成纳入统一流程，并通过消融实验和外部验证检验其有效性。

## 2.1 研究内容

本项研究围绕氟斑牙分级辅助报告生成，开展五项相互衔接的研究，总体关系如图 3 所示。

**1）氟斑牙分级数据与标签体系构建。** 针对现有数据规模有限、分级口径不完全一致的问题，在团队已有数据和公开 DFID 的基础上，完成图像、患者、类别、来源和质量盘点；以“正常、轻度、中度、重度”四级为主线，建立图谱档位、样本文件名与公开数据标签之间的映射表，图谱中的“可疑、极轻”暂不单列，原始标签保留；按患者划分训练、验证和测试集，测试集只用于最终验收；设计报告字段与双医生标注、仲裁流程，为后续分级和报告评价提供统一基准。

**2）视觉证据驱动的氟斑牙分级模型。** 针对病灶区域小、边界不清、染色和光照干扰等问题，构建共享 CNN/Transformer 视觉编码器，先完成牙齿区域定位/分割，再进行四级分级；在分类损失中引入有序（Ordinal）约束，并采用证据深度学习（EDL）输出类别概率、证据强度及总体/数据/模型不确定性；通过校准和选择性预测，为低置信度样本转人工提供依据。

**3）视觉—语言证据对齐。** 针对分级结果难以说明“依据什么”的问题，复用第（2）项研究的区域特征，定义部位、征象、否定、不可判断和证据 ID 等字段，将医生描述中的关键征象与图像区域对齐；输出结构化的视觉证据表，使每条视觉断言都能回溯到具体牙位、牙面和图像区域，而不是只给出类别或热图。

**4）知识增强与可追溯报告生成。** 针对报告术语不规范、知识来源不可追溯的问题，构建面向氟斑牙分级与鉴别的证据表/知识库，每条知识保留来源文献 ID、页码、适用范围、证据等级、版本和审核记录；检索模块根据视觉证据表返回片段、来源、版本和审核记录；报告生成模块在证据约束下输出结构化 JSON 与短叙述，并执行事实校验、一致性校验和安全边界校验，低置信度或证据冲突样本转医生审核。

**5）可信评价与外部验证。** 针对现有研究评价维度单一的问题，从分级、报告、检索和校准四个方面建立评价协议：分级采用 macro-F1、QWK 和逐类召回；报告采用字段 F1、遗漏率、无依据陈述率、结构有效率和医生盲评；检索采用 Recall@k、引用覆盖率和引用支持率；校准采用 ECE、Brier 和风险—覆盖率。通过 ±RAG × ±不确定性门控等消融实验隔离各组件贡献，并在 DFID 和（如可得）独立机构同模态补标集上进行验证。

## 2.2 研究目标

本研究拟达到以下目标：

（1）建立可复核的氟斑牙四级标签与报告字段规范，完成患者级数据划分和双医生试标，形成数据与标注说明；

（2）构建视觉证据驱动的分级模型，在统一患者级划分上取得与现有公开方法可比的 macro-F1 和 QWK，并给出校准与选择性预测结果；

（3）建立视觉—语言证据对齐模块，使部位、征象、否定和不可判断项能够回溯到证据 ID，并完成定位一致性评价；

（4）构建知识增强的报告生成流程，输出结构化 JSON 与短叙述报告，完成引用覆盖率、引用支持率和无依据陈述率评价；

（5）完成内部验证和（如可得）外部补标集验证，形成可复现的实验记录、原型系统和论文初稿。

## 2.3 拟解决的关键科学问题

（1）**分级定标与标签一致性。** 在《氟斑牙诊断图谱》档位、样本文件名和公开数据标签不完全一致的条件下，如何建立可复核的四级标签体系，并保证患者级划分、牙齿级判定与报告字段一致？这是后续所有指标可比的前提。

（2）**视觉证据与语言证据的对齐。** 在病灶小、边界不清、遮挡、染色干扰和相邻级别混淆的条件下，如何使模型输出的部位、征象、否定和不可判断项稳定回溯到图像区域，而不是生成流畅但无依据的描述？

（3）**知识接地与幻觉可测。** 如何将图像证据与知识证据分开溯源，并以引用覆盖率、引用支持率和无依据陈述率等指标，可复现地评价报告的事实性？检索能补充知识，但不能恢复缺失的图像证据，二者应分别验证。

（4）**不确定性与人工复核。** 如何联合 EDL 不确定性、检索证据强度和报告风险，构建可判定的“直接生成/补充检索/转人工”决策规则，并在控制转诊率的同时降低高置信错误？相关阈值需在试标后确定，不预先编造。

## 3.1 研究方法

本研究采用实验法、经验总结法、比较研究法以及文献资料法开展研究工作。以实验法为基础，结合医学图像分类、视觉语言对齐、知识检索与报告生成领域的文献资料和相关研究者的经验总结，作为本课题的辅助工作；同时通过双医生标注与仲裁建立参考标准，通过对比实验、消融实验和统计检验验证方法有效性。

## 3.2 技术路线及实验手段

本研究拟采取的研究方案如图 4 所示，按照“数据与定标—视觉分级—证据对齐—知识检索—报告生成—验证总结”的流程展开，各阶段之间通过统一的证据表和字段规范衔接。

**阶段一：数据与定标。** 对团队数据和公开 DFID 进行盘点，记录患者数、图像数、类别、来源、质量和重复情况；以四级（正常、轻度、中度、重度）为主线，建立图谱档位、样本文件名与公开数据标签的映射表，原始标签保留；按患者划分训练、验证和测试集，测试集只在模型定型后使用；设计报告字段，开展双医生独立标注与仲裁试标，记录字段级一致性和修订率。该阶段流程如图 5 所示。

**阶段二：视觉分级。** 构建共享 CNN/Transformer 编码器，先完成牙齿区域定位/分割，再进行四级分级；在分类损失中引入 Ordinal 约束，并采用 EDL 输出类别概率、证据强度和总体/数据/模型不确定性；在统一划分上与 ResNet、ViT、Swin、Gu 等[2]、MLTrMR[3]、LD2Net[4]等基线比较，并进行校准与选择性预测分析。该阶段结构如图 6 所示。

**阶段三：视觉—语言证据对齐。** 复用阶段二的区域特征，定义部位、征象、否定、不可判断和证据 ID 等字段；将医生描述中的关键征象与图像区域对齐，输出结构化视觉证据表；通过字段级 F1、证据 ID 命中率和区域遮挡测试评价对齐质量。该阶段如图 7 所示。

**阶段四：知识库与报告生成。** 构建面向氟斑牙分级与鉴别的证据表/知识库，每条知识保留来源文献 ID、页码、适用范围、证据等级、版本和审核记录；检索模块根据视觉证据表返回片段、来源、版本和审核记录；报告生成模块在证据约束下输出结构化 JSON 与短叙述，并执行事实校验、一致性校验和安全边界校验，低置信度或证据冲突样本转医生审核。该阶段如图 8、图 9 所示。

**阶段五：评价与外部验证。** 实验矩阵见表 4，包括分级基线（E1）、不确定性（E2）、证据对齐（E3）、报告生成（E4）、消融（E5）、外部验证（E6）和效率与鲁棒性（E7）。分级采用 macro-F1、QWK 和逐类召回；报告采用字段 F1、遗漏率、无依据陈述率、结构有效率和医生盲评；检索采用 Recall@k、引用覆盖率和引用支持率；校准采用 ECE、Brier 和风险—覆盖率。外部验证优先使用独立机构同模态补标集；DFID 许可已确认可得，可作为分级线索和补充验证；SFXRay 属于氟骨症 X 线任务，不作为氟斑牙照片任务的直接外测。

## 3.4 关键技术

（1）**分级标准映射与患者级数据划分技术。** 针对图谱档位、样本文件名和公开数据标签不一致的问题，建立可追溯的映射表和患者级划分规则，保留原始标签，保证训练、验证、测试之间无患者重叠。

（2）**共享视觉编码与不确定性分级技术。** 采用共享 CNN/Transformer 编码器完成牙齿区域定位、特征提取和四级分级，结合 Ordinal 约束与 EDL 输出类别概率、证据强度和不确定性，为低置信度样本转人工提供依据。

（3）**视觉—语言证据对齐技术。** 将部位、征象、否定、不可判断和证据 ID 定义为统一字段，把医生描述中的关键征象与图像区域对齐，使报告中的视觉断言可回溯到具体牙位、牙面和图像区域，而不是仅输出类别或热图。

（4）**可追溯知识检索与证据表构建技术。** 构建带来源、页码、适用范围、证据等级、版本和审核记录的知识条目，检索时返回片段及其来源信息；未核验知识标注“待核验”，避免把检索片段直接当作图像证据。

（5）**受约束报告生成与校验技术。** 在视觉证据表和检索片段约束下生成结构化 JSON 与短叙述，执行事实校验、一致性校验和安全边界校验；校验失败或证据冲突时回退模板或转医生审核，保证报告可审核、可追溯。

## 3.5 可行性分析

从理论和技术方面分析，CNN/Transformer、视觉语言模型、检索增强生成和 EDL 均有较成熟的研究基础；团队在氟斑牙分割、分级方向已有公开论文积累[2-6]，为本研究提供了方法参考。从数据和实验方面分析，团队已有四级氟斑牙图像数据，公开 DFID 许可可得，数据扩充和患者级划分具备可操作性；实验室具备开展深度学习实验的 GPU 服务器和数据存储条件（具体配置据实填写），可采用轻量模型和冻结骨干控制算力需求。从临床合作方面分析，拟邀请合作口腔医生参与分级定标、双医生标注与仲裁，并争取独立机构同模态补标集；伦理审批、数据许可和未成年人监护人同意按实际要求办理。

同时设置止损条件：若报告字段级 kappa 或医生修订率在试标后达不到预设阈值，则退回可解释分级主线；若证据约束生成相对“分级套模板”无显著增益，则保留模板方案；若外部补标集无法落实，则如实报告内部验证和 DFID 补充验证结果。综上所述，本研究在理论、技术、数据和平台方面具备可行性，研究内容和时间安排合理，可按计划推进。

## 4. 论文研究的特色与创新之处

本研究的特色在于将氟斑牙分级、视觉证据对齐、知识检索和报告生成纳入统一流程，使分级结果能够转化为可审核、可追溯的辅助报告。具体创新点如下：

（1）**视觉证据约束的报告生成。** 不同于直接由图像端到端生成自由文本，本研究先输出由部位、征象、否定、不可判断和证据 ID 组成的视觉证据表，再在证据约束下生成结构化报告，期望降低无依据陈述率并提高字段级准确率；该创新点通过 E4、E5 验证。

（2）**图像证据与知识证据分离溯源。** 将“图像可证”的视觉断言与“知识可证”的分级依据、鉴别说明分开记录和评价，分别计算引用覆盖率与引用支持率，避免把检索片段直接当作图像证据；该创新点通过 E4、E5 验证。

（3）**不确定性驱动的复核策略。** 联合 EDL 不确定性、检索证据强度和报告风险，构建“直接生成/补充检索/转人工”的分级复核规则，期望在控制转诊率的同时降低高置信错误；该创新点通过 E2、E5 验证。

（4）**面向基层筛查的结构化辅助报告。** 报告采用结构化字段加短叙述的形式，兼顾可读性与可统计性，便于医生快速审核、质控和流行病学统计；该创新点通过 E4 和医生盲评验证。

需要说明的是，上述创新点的效果均需通过实验验证，本文不预设其一定成立；若某项假设未获支持，将按 3.5 的止损条件调整研究重点。

（5）大模型训练与推理所需的部分算力、临床合作正式协议尚需落实。

#### 2.3 拟解决的途径

（1）**数据方面：** 先进行小规模试标，确定分级标准和报告字段，再按患者级划分逐步扩大数据；对重复、低质量和无法判读的图像建立筛查与记录规范；通过公开 DFID 补充分级样本，但明确其任务和标签差异。

（2）**标注方面：** 与合作口腔医生制定标注手册，采用双人独立标注、第三人仲裁，记录字段级 kappa、修订率和标注耗时；先完成小样本一致性评估，再决定是否扩大标注规模。

（3）**外部验证方面：** 优先争取独立机构同模态病例并由当地医生补标；若无法落实，则如实报告内部验证和 DFID 补充验证结果，不夸大泛化能力。

（5）**算力与工程方面：** 优先使用轻量模型、冻结骨干和 LoRA 等参数高效方法，分阶段开展实验；必要时申请实验室或云平台算力支持。
